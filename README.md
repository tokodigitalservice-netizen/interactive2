# インタラクティブ動画サービス概要　2026/08/20

本資料は、インタラクティブ動画サービスのサービス構成を示したものです。

## 1. 全体構成

インタラクティブ動画は全体で大きく２つのサービスが連携して動いています。

1. 親サイト
    * 2.動画再生サイトは親サイトのモーダルとして表示されます。
    * リンク元サイトを大きく改修することなくこの親サイトのURLのリンクを設定してサービス提供が可能です。

2. 動画再生サイト
    * モーダルとして表示する動画内容を制御しているサービスです。
    * 既存サイトから直接呼びだすことも可能です。
