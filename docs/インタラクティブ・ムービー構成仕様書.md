
# インタラクティブ・ムービー構成仕様書

## 1. 概要

本システムは、JSON形式で定義されたシナリオに従い、動画の再生と動的な選択肢生成を行うWebアプリケーションである。ユーザーの選択に応じて動画が切り替わり、最終的なゴール（エンドページ）へと遷移する。

## 2. データ構造 (JSON)

システムが参照するJSONデータは、以下のトップレベル項目で構成される。

| キー | 型 | 役割 |
| --- | --- | --- |
| `totalSteps` | Number | 進捗表示（ステップ数）の計算に使用 |
| `currentURL` | String | 動画ファイルが格納されているベースURL |
| `closeUrl` | String | モーダル閉じるボタンの遷移先 |
| `q1`〜`endN` | Object | 各シーン（質問・エンド）の定義オブジェクト |

### シーン定義オブジェクトの仕様

各シーンキー（`q1`, `q1A` 等）の中身は以下の通り。

| キー | 役割 |
| --- | --- |
| `text` | 動画上に表示される質問テキスト |
| `videoUrl` | `currentURL` の後に結合される動画ファイル名 |
| `choices` | 選択肢キーと、次へ遷移するシーンIDのマップ |
| `button` | 選択肢ボタンに表示するラベルのマップ |
| `result` | (endシーンのみ) 結果表示エリアのテキスト |
| `endUrl` | (endシーンのみ) リンクボタンの遷移先 |
| `endMessage` | (endシーンのみ) リンクボタンの表示ラベル |

## 3. システム仕様

### 3.1 動画制御

* **再生**: `video`要素を用い、`autoplay`、`loop`で再生。
* **URL生成**: `currentURL` + `videoUrl` を動的に結合して取得。

### 3.2 UIコンポーネントの挙動

* **choices-container**:
* 画面中央下部に配置。
* マウスの動き（`mousemove`）を検知し、下部エリア（画面の高さ80%以下）にカーソルがある場合に表示。
* 一定時間（3秒）無操作で `hidden` クラスが付与され、フェードアウトして非表示になる。


* **ボタンレイアウト**:
* `flex: 0 0 auto` によりサイズを固定（200px幅）。
* `justify-content: center` により中央寄せで配置。

### 3.4 遷移先指定方法

* **choices**で指定された要素に遷移先のIDを指定することで、遷移先が決定される。

(設定例)
``` json
  "q1": {
    "text": "Q1：Q1です",
    "videoUrl": "movie_q1.mp4",
    "button": {
      "L": "はい",
      "R": "もどる"
        },
    "choice": {
        "A": "q2A",
        "B": "q2D"
        }
    },
      "q2A": {
    "text": "Q2D：四番です。本当に進みますか？",
    "videoUrl": "movie_q2B.mp4",
    "button": {
      "L": "はい",
      "R": "もどる"
        },
    "choice": {
        "A": "q2",
        "B": "q2D"
        }
    },
  "q2D": {
    "text": "Q2D：四番です。本当に進みますか？",
    "videoUrl": "movie_q2B.mp4",
    "button": {
      "L": "はい",
      "R": "もどる"
        },
    "choice": {
        "A": "q2",
        "B": "q2A"
        }
    },
```
上記例では、左ボタン（キーはA）をクリックするとメインキーq2に遷移し、右ボタン（キーはB）をクリックするとメインキーq2Aへ遷移する設定となる。


### 3.4 遷移ロジック

* **歴史管理 (`history` 配列)**: 選択肢を辿った履歴をスタックとして保持し、「前に戻る」ボタンによる直前のシーンへの復帰を実現。
* **エンド判定**: シーンIDが `end` で始まる場合、質問モードを終了し、結果表示モードへ遷移。

## 4. 追加・修正時のガイドライン

### 動画を追加する場合

1. 動画ファイルをアップロード（R2バケットなど）する。
2. JSONの各シーン（`qX`）に新しいキーを追加する。
3. `videoUrl` にファイル名を指定する。
4. `choices` に遷移先のキーを追加する。

### ボタンの見た目を変更する場合

* `index.html` 内の `<style>` タグ下部、`button.choice-btn` セレクタを修正してください。
* 現在は半透明の白背景（`rgba(255, 255, 255, 0.3)`）が設定されています。

### 進捗バーやステップの仕様変更

* JSONの `totalSteps` を変更することで、自動的にプログレスバーの計算が追従します。（現在この機能はディセーブル(display: none;)としているので、必要に応じて表示させることも可能。

### 技術的補足

* **CSS**: モバイル時には `media (max-width: 600px)` により、`choices-container` が縦並び（`column`）に切り替わるレスポンシブ対応となっています。ただし利用環境はPC前提としています。
* **JavaScript**: `loadQuestion` 関数がレンダリングの核心であり、JSONの取得とキャッシュを初回実行時に行う仕組みです。
