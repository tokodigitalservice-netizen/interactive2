# インタラクティブ動画サービスを他サイトへ移植する場合のポイント

2026年6月12日

本サイトはデモ用であるため、実際に機能を実装する場合には以下の内容を対象サイトに追加する必要があります。

## 実装される内容

### ＜対象リンクをクリックすることでモーダル画面を表示し、動画を再生する機能＞

参考）モーダル画面：ページ遷移せずに現在のページ上に重ねて表示するポップアップウィンドウのこと。

※モーダルで表示される動画は、外部サービスとして稼働中のものです。

## 追加点

### リンクに関する記述

```html
<div class="card" onclick="openDiagnosis('https://video-story-common.pages.dev/?config=/main.json')" style="cursor: pointer;">
```

### 現在の実装コード

```html
    <div class="card" onclick="openDiagnosis('https://video-story-common.pages.dev/?config=/main.json')" style="cursor: pointer;">
      <div class="card-inner">
        <p class="card-number">02</p>
        <h2 class="card-title-sub">開発中</h2>
        <h2 class="card-title"> インタラクティブ動画</h2>
      </div>
    </div>
```

ポイント）
1. openDiagnosis関数の引数で指定されているのがリンク先URLです。
2. リンク先URLはconfig=をパラメタとして動画表示サービスが個別処理定義ファイル(上記の場合はmain.json)を参照して動作するための指定です。
3. 現在のリンク先はcloudflare pages上で稼働中で、動画ファイルはcloudflare R2のバケットを参照している独立した外部サービスです。

※classやstyleは現行のものに合わせるなど、必要に応じて調整してください

### モーダル画面並びに表示時の終了ボタン（X）を表示するための記述

```html
<!-- モーダル本体 × 2 -->
<div id="video-modal" onclick="closeDiagnosis()">
  <button id="modal-close" onclick="closeDiagnosis()">✕</button>
  <iframe id="diag-frame" src="" style="width:100%; height:100%;"></iframe>
</div>

<div id="detail-modal" onclick="closeDetailModal()">
  <button id="detail-close" onclick="closeDetailModal()">✕</button>
  <iframe id="detail-frame" src="" style="width:100%; height:100%;"></iframe>
</div>

```

ポイント）
1. 現在は親モーダル内にボタンを設定し、クリックされると子モーダルを表示します。
2. 子モーダル表示中は親モーダルはポーズ状態となるため、その制御で２つの同様な定義が必要です。（両者の記述はほぼ同じですが、idが異なります）

※styleは現行サイトに合わせ、必要に応じて調整してください。

### cssならびにjavascriptの追加

modal.cssならびにscript.jsを新たに参照する、あるいは記述内容をそれぞれ全て当該ファイルへ追加してください。

### 紹介用サイト https://interactive-common.pages.dev/

ユーザのサイトに上記のjavascriptやcssを組み込むことが困難な場合には、リンクを設定するだけでインタラクティブ動画を再生する環境設定が可能です。

指定方法）

紹介用サイトURLにパラメタを追加する。

```
// 例
https://interactive-common.pages.dev?url=https://video-story-common.pages.dev?config=main2.json

```

画面ロード直後に参照するURLとそれに必要なjsonをパラメタとして指定します。

```
// パラメタ部分のみ
?url=https://video-story-common.pages.dev?config=main2.json
```
