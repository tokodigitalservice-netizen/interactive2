## 診断設問データ定義仕様書

2026/04/14　第2版

### 1. 概要
本資料は、アプリケーション内蔵の「パーソナルカラー診断」機能で使用する設問および診断結果のデータ構造を定義するものです。回答に応じた分岐（遷移先）と、フロントエンド（`shindan.html`）での動的なコンテンツ制御（動画再生、プログレスバー更新）に利用します。

### 2. ファイル構成
* **ファイル名**: `questions.json`
* **データ形式**: JSON (JavaScript Object Notation)
* **構造**: 単一のオブジェクト（Key-Value形式）

```json
{
  "totalSteps": 2,
  "q1": {
    "text": "Q1:好きな色はどちらですか？",
    "button": { "L": "情熱の赤", "R": "冷静の青" },
    "choices": { "A": "q2A", "B": "q2B" }
  },
  "end1": {
    "text": "診断結果１",
    "result": "あなたは暖色系のパーソナルカラーです"
  }
}
```

### 3. フィールド定義

#### 3.1. ルート要素
| フィールド名 | 型 | 説明 | プログラムでの利用 |
| :--- | :--- | :--- | :--- |
| **`totalSteps`** | Number | 診断完了までの総設問数 | `updateCommonUI` 関数でプログレスバーの％計算に使用します。 |
| **`[key]`** | Object | 設問または結果の定義体 | `id` として参照され、対応する動画（`id.mp4`）の再生キーにもなります。 |

#### 3.2. 設問オブジェクト（q1, q2A...）
| フィールド名 | 型 | 説明 | 備考 |
| :--- | :--- | :--- | :--- |
| **`text`** | String | 画面中央に表示される設問文 | `question-text` 要素に反映されます。 |
| **`button`** | Object | 選択肢ボタンのラベル定義 | `L`（左ボタン）、`R`（右ボタン）の文言を指定します。 |
| **`choices`** | Object | 次の遷移先IDの指定 | `A`（左選択時）、`B`（右選択時）の遷移先ID。`next()` 関数に渡されます。 |

#### 3.3. 結果オブジェクト（end1, end2...）
| フィールド名 | 型 | 説明 | 備考 |
| :--- | :--- | :--- | :--- |
| **`text`** | String | 結果画面のタイトル | IDが `end` で始まる場合、結果表示モードに切り替わります。 |
| **`result`** | String | 最終的な診断結果文 | `result-text` 要素に表示されます。 |

### 4. システム連動仕様
本JSONファイルは、`shindan.html` 内の以下のロジックと密接に連動しています。

* **動的動画再生**: 
    * 読み込まれた項目のIDに基づき、`${r2BaseUrl}${id}.mp4` の形式でCloudflare R2上の動画を自動再生します。
* **プログレス管理**:
    * `history` 配列の長さと `totalSteps` を比較し、「ステップ n / m」という進捗表示を自動計算します。
* **状態の初期化**:
    * `loadQuestion` 関数が呼ばれるたびに、前回の設問文やボタンの状態をクリアし、新しいデータでUIを再構築します。

### 5. 技術的要件・注意事項

* **JSON構造の厳守**:
    * 階層構造（入れ子）を維持するため、`{ }` の閉じ忘れに注意してください。
* **遷移先の整合性**:
    * `choices` で指定した遷移先ID（例: `q2A`）がファイル内に存在しない場合、スクリプトは「データが見つかりません」とエラーを出力します。
* **文字と数値の区別**:
    * `totalSteps` は計算に使用するため、必ず **""（ダブルクォーテーション）で囲まない数値型** で記述してください。その他のテキスト項目は必ず "" で囲む必要があります。
* **文字コード**:
    * 日本語を正しく表示するため、保存形式は `UTF-8` を遵守してください。
